# 로드맵

## 🎯 지금의 목표

**v0.1 — "일단 쓸 수 있는 상태"**

펫이 화면을 돌아다니는 골조와 메인 창 레이아웃을 먼저 만들고, 그 위에 **대전 버스 위젯**을 붙인다.
TTS(하치와레 목소리)는 앱 개발과 별개로 [병렬 트랙](#병렬-트랙-v-하치와레-목소리-tts)에서 진행한다.

**v0.1 완료 조건**: 설치 파일로 설치한 앱에서 펫이 돌아다니고, 즐겨찾기한 정류소의 버스 도착 알림을 펫이 말풍선으로 알려준다.

```
앱 트랙    Phase 0 → Phase 1 → Phase 2 → (v0.1) → Phase 3 → Phase 4 → Phase 5
음성 트랙  V1 → V2 → V3 → V4

트랙 간 연결
  V2 받아쓴 대사     → Phase 4 페르소나 말투 예시
  V4 고정 반응 음성  → Phase 3 클릭 반응 (선택 사항, 없으면 말풍선만)
  V4 TTS 서버        → Phase 5
```

## 병렬 트랙 V. 하치와레 목소리 (TTS)

앱 개발과 독립적으로 진행한다. 결과물은 Phase 3(고정 반응 음성), Phase 4(대사 예시), Phase 5(TTS 서버)에서 사용한다.

> 공개 저장소에는 범용 스크립트만 둔다. 수집 대상 영상 주소·구간, 오디오, 받아쓴 대사, 모델은 모두 로컬 전용(`voice/` 아래 `.gitignore` 대상)이다.

## 보안 체크리스트

각 항목은 해당 Phase의 작업으로도 들어가 있다. 이 목록은 전체 점검용이다.

**Electron**
- [x] 모든 창(오버레이 포함): `contextIsolation: true`, `nodeIntegration: false`, `sandbox: true`
- [x] preload는 기능 단위 API만 노출 (`ipcRenderer`·`electronAPI` 통째로 노출 금지)
- [x] 메인 프로세스 IPC 핸들러: 인자를 Zod로 검증, 요청한 창(sender) 확인
- [x] 엄격한 CSP, 앱 내 페이지 이동·새 창 차단 (`will-navigate`, `setWindowOpenHandler`)
- [x] 권한 요청(카메라·마이크 등) 전부 거부 — 필요한 기능이 생기면 해당 권한만 허용
- [x] 외부 링크는 `shell.openExternal` + https 허용 목록만
- [x] `pack://` 핸들러는 팩 루트 밖 경로 차단 (정션·대체 데이터 스트림·장치 이름 포함)
- [x] Electron Fuses: RunAsNode · NodeOptions · inspect · GrantFileProtocolExtraPrivileges 비활성(렌더러는 `app://`로 서빙), asar 무결성 검사

**API 키**
- [ ] 키는 메인 프로세스에서만 복호화·사용. 렌더러에 원문을 돌려주는 IPC(`getSecret` 등) 없음, 테스트 호출도 메인에서 저장된 키로
- [x] `safeStorage`를 쓸 수 없으면 저장 거부 (평문 저장 금지)
- [ ] `.env`에 `MAIN_VITE_` 키 금지 (빌드 결과물에 포함됨)
- [ ] 로그·에러 메시지에서 키 마스킹 (특히 URL에 키가 붙는 공공데이터포털 `serviceKey`)
- [ ] Gemini 키는 쿼리 파라미터가 아닌 헤더(`x-goog-api-key`)로 전송
- [ ] 대전 버스 API https 지원 여부 확인 → 지원 시 https 사용
- [x] 설정에 키 삭제 기능

**콘텐츠 · LLM**
- [ ] LLM 답변·외부 API 응답은 텍스트로 렌더링 (HTML 렌더링 금지, 마크다운은 sanitize 후)
- [ ] 나중에 LLM에 도구(버스 조회 등)를 붙이더라도 모델 출력만으로 부작용 있는 동작을 실행하지 않음 (프롬프트 인젝션)

**TTS / 모델**
- [ ] GPT-SoVITS API는 인증 없는 GET으로 모델 경로를 받음 → 앱이 실행·종료하고, 랜덤 포트 + 요청 토큰(또는 `Origin` 헤더 요청 거부) 래퍼, 가중치 경로는 앱이 고정
- [ ] 음성 모델(`.pth` / `.ckpt`)은 직접 학습한 것만 사용 — PyTorch 모델 파일은 로드 시 코드 실행 가능

**의존성**
- [x] pnpm 빌드 스크립트 허용은 `pnpm ignored-builds`로 확인된 필요한 패키지만
- [ ] Electron 주기적 업데이트 (Chromium 보안 패치) — 자동 업데이트가 생기기 전까지는 새 릴리스를 직접 설치해야 반영됨

## 구조

```
Electron
 ├─ 펫 오버레이 창 (React, 디스플레이당 1개)   투명 · 항상 위 · 클릭 통과, 렌더링만 담당
 ├─ 메인 창 (React)                           홈 / 버스 / 대화 / 펫 / 설정
 └─ 메인 프로세스 (Node)
     ├─ 펫 상태      위치 · 상태 머신 (전역 DIP 좌표) → 오버레이 창에 push
     ├─ 설정 · 키    settings.json / secrets.json (safeStorage)
     ├─ 팩 로더      pack:// 프로토콜
     ├─ 버스         공공데이터포털 대전 버스 API + 폴링 스케줄러
     ├─ LLM          Gemini / Claude (제공자 교체 가능)
     └─ TTS          GPT-SoVITS API 서버 (자식 프로세스, 127.0.0.1)
```

- 외부 API 호출은 메인 프로세스에서 처리한다 (CORS 회피, API 키를 렌더러에 노출하지 않음).
- Electron에서는 Web Speech API가 동작하지 않는 것으로 알려져 있어, STT는 별도 엔진이 필요하다.

## 개발 환경 메모

- Windows 10, Node 24.22 (nvm-windows), pnpm 10, Python 3.12
- VS Code: Biome 확장 설치됨 (ESLint / Prettier 확장도 있으므로 이 프로젝트는 `.vscode/settings.json`으로 Biome를 기본 포맷터로 지정)
- GPU: GTX 970 (4GB, Maxwell) — PyTorch 2.8+의 CUDA 12.8/12.9 빌드는 Maxwell 미지원, **cu126 빌드는 2.14까지 지원** (2.15부터 cu126 빌드 중단 예정). 로컬 GPU 추론은 cu126 빌드로, 안 되면 CPU
- 음성 트랙용으로 추후 설치: yt-dlp, ffmpeg, uv (Python 환경 관리)
