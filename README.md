# desktop-pet

바탕화면을 돌아다니는 데스크탑 펫이자, 말 걸면 대답해주는 개인 비서.

> 🚧 개발 초기 단계

## 계획 중인 기능

- [ ] 투명 창 위를 돌아다니는 펫 (드래그, 클릭 반응)
- [ ] 펫 팩 구조 — 캐릭터(스프라이트·성격·목소리)를 팩 단위로 추가/교체
- [ ] LLM 대화 + 캐릭터 목소리 TTS (GPT-SoVITS)
- [ ] 대전광역시 실시간 버스 도착 정보
- [ ] 마이크 음성 인식 (추후)

## 기술 스택

- Electron + React + TypeScript
- TTS: GPT-SoVITS (로컬 Python 서버)
- LLM: Gemini API

## 에셋 안내

이 저장소에는 **캐릭터 이미지, 음성 데이터, 학습된 음성 모델이 포함되어 있지 않습니다.**
펫 팩은 각자 로컬의 `packs/` 폴더에 직접 준비해야 합니다.

첫 번째 펫 팩으로 사용 중인 「ちいかわ」 캐릭터의 저작권은 ナガノ에게 있으며,
이 프로젝트는 개인 용도의 비공식 팬 프로젝트입니다.
